# altora-posts

Assets públicos dos posts da ALTORA. As imagens aqui são hospedadas só para
publicação automática no Instagram via Meta Graph API (a Meta busca cada slide
por URL pública, não aceita arquivo local).

Estrutura: uma pasta por carrossel (`carrossel-N/slide-01.png ...`).

URL base de cada pasta (usar em `PUBLIC_IMG_BASE` no `.env` do MazyOS):
`https://raw.githubusercontent.com/Guss-Avila/altora-posts/main/<pasta>`
